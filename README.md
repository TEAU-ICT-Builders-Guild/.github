# 🏛️  TEAU ICT Builders Guild

> **Practical Engineering • Open-Source Systems • Edge & AI Innovations**

Welcome to the official GitHub Organization of the **TEAU ICT Builders Guild** at **The East African University**. We are a student-led engineering community focused on moving beyond theory into production code, low-level system design, embedded hardware, and AI application frameworks.

___

## 🎯 Our Core Mandate
- **🛠️ Practical Execution:**  Building real-world, production-ready software and hardware applications.
- **🌐 Open-Source Culture:** Training members in collaborative Git/GitHub workflows, code review, and open-source contributions.
- **🚀 Industry Readiness:** Aligning student projects with global tech initiatives, including Developer Programmes and Student Ambassador tracks.
- **⚡ Peer Mentorship:** Connecting junior and senior students across specialized domain tracks (AI, Systems/Hardware, Cloud/Web, CyberSec).

___

## 🛠️ Guild Technical Focus Areas

| Track | Primary Focus & Technologies |
|-------|------------------------------|
| **🤖 AI & Data Systems** | FastAPI, LLM Integration, Vector Databases, Python, PyTorch, Agentic Dev |
| **⚡ Hardware & Embedded** | Microcontrollers, Microgrids, Real-Time C/C++, Arduino, Telemetry, Bare-Metal Programming |
| **☁️ Web & Cloud Systems**  | React, Next.js, TypeScript, REST APIs, Linux Admin, Docker |
| **🛡️ CyberSec & Systems**  | Active Directory, Linux Administration, Network Infrastructure |

## 🚀 Getting Started for Members
1. **Join the Digital Hub:** Connect to our [Discord Server](https://discord.gg/aPneVcC2Z) and official [WhatsApp Community](https://chat.whatsapp.com/LD9L9CbBOs89jrZZbVFAeI)
2. **Setup Your Environment:** Install `git`, create a personal GitHub account, and configure your Personal Access Tokens or SSH keys.
3. **Submit Your First PR:** Pick a beginner issue in our `workshops-2026` repository or fork a Guild project.
4. **Read the Guidelines:** Review or [`CONTRIBUTING.md`](./CONTRIBUTING.md) to understand our commit standards and pull request workflows.
